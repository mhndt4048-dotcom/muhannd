# To-Do List 📝

A simple To-Do List project built with Python for beginners.

## Features

- Add tasks
- Show tasks
- Delete tasks
- Mark tasks as completed
- Exit the program

## How to run

Make sure Python is installed, then run:

```bash
python main.py
```

## What I learned

This project practices:

- Lists
- Dictionaries
- Variables
- Input and output
- `if / elif / else`
- `while` loops
- `for` loops
- `try / except`
- Basic Python data handling
